# Core Link Decisions

Record durable project decisions here.

## Product Direction

- Use `Core Link` for player-facing naming. Do not call it a rig.
- The MVP is a native Wear OS pixel-game prototype, not a dashboard.
- First launch should feel like Core Link OS booting a recovered high-tech device.
- The main surface should be one watch-sized game scene with an animated pixel Nanobot Core and compact bottom commands.
- Static cards/counters are not acceptable as the primary game experience even if mechanics work.

## Story Direction

- Use `CoreTech` as the canonical corporation name for now. Treat `Cortex` as an older draft/slip unless deliberately revisited.
- Use `ArcKin` for the embodied AI beings. Keep `ARC` as the technical/corporate term for Artificial Reasoning Core.
- Use `K.I.N.` only as **Kernel Intelligence Network**.
- Every ArcKin should have a front-facing hexagon ARC screen somewhere visible on its body; this is the top of the slotted ARC, can show text/symbols/emojis, and lights up when the ArcKin speaks.
- Use the CoreTech logo direction from Miguel's front-facing `410` badge: a hexagon ring with negative-space seams cutting through the ring at the six corners. Do not use a center dot, inner hub, or spokes radiating from the center. The face hexagon is the ARC/status screen; the chest hexagon is the CoreTech brand mark.
- Current CoreTech brand visual reference: `assets/images/references/coretech-branding/coretech-brand-sheet-corner-cut-hex-v3.png`.
- CoreTech uses a split human badge system. Normal corporate employees wear identity badges with photo, name, department/role, permanent ID, CoreTech logo, and a subtle access stripe or corner tab. K.I.N. cybersecurity agents wear anonymous shift badges with rotating daily agent codes such as Miguel's `410`. Clearance colors and L-level labels are for ArcKin units, not ordinary human staff.

- Current K.I.N. cybersecurity division visual reference: `assets/images/references/coretech-kin-cybersecurity/coretech-kin-cybersecurity-division-reference-v1.png`.
- Current opening-scene K.I.N. room establishing visual reference: `assets/images/references/coretech-kin-cybersecurity/corelink-scene-01-kin-room-working-establishing-v5-wide-quiet.png`.
- Current closed-door opening-room variant: `assets/images/references/coretech-kin-cybersecurity/corelink-scene-01-kin-room-working-establishing-v9-door-clear-no-left-worker.png`.
- Current Miguel Garcia / Agent 410 standalone reference: `assets/images/references/miguel-garcia-agent-410-father/miguel-garcia-agent-410-reference-v2-correct-logo.png`.
- CoreTech overseer ArcKin are sleek white corporate shells with chest logo, legible unit identifier, shoulder clearance level, and two offset parallelogram shoulder stripes colored by clearance.
- CoreTech clearance colors: L0 grey, L1 green, L2 yellow, L3 blue, L4 orange, L5 red. The K.I.N. cybersecurity room overseer is L3 blue by default and uses identifier `OSR-L3-072`.
- `Agent 410` is canonical for the father; the 410 number is Miguel's anonymous K.I.N. daily shift code on the day of the opening incident and intentionally echoes HTTP `410 Gone`.
- In the opening, Miguel uses a memorized Level 5 encryption-key fragment, not a complete master key. He learned it months earlier during a Level 5 breach-review/rotation workflow, preserved it through a mnemonic, and combines it with his current Level 3 sandbox privileges to give the Net Divers a narrow bridge/trust path into a protected K.I.N. sector.
- The Net Divers use Miguel's fragment and bridge to brute-force encrypted folder structures tied to a rumored CoreTech black-box project codename. They have rumors and leaked intelligence, not the full truth yet.
- Miguel's interrogation-room sequence is canon for now as a staged evaluation: a sterile room with a small TV above the door, a fake plant, an awkward wait, a lifeless overseer in the corner, a female overseer voice reading his record and Level 5 review history, then a live feed of Grace and the family before the hidden Presence escalates the scene into the ArcKin overseer/nanofabricator demonstration.
- Use `nanofabricators` for the invisible A.R.C.-directed fabricator swarm in the Agent 410 death demonstration. They assemble, repair, and obey ArcKin/A.R.C.s. The exact organic/neural effect on Miguel should remain unclear to the reader in the first issue and be revealed later.
- Comic scene work should be saved under `knowledge/projects/corelink/comic/`. The first issue is `issue-001` with no final title yet. `chapter-001` covers the K.I.N. cybersecurity-room opening through Miguel's interrogation/death cleanup, with one `working-canon` Markdown file per scene.
- `Net Divers` are the broad class of K.I.N. operators. `The Sentinels` are an elite resistance faction/cell of Net Divers.
- Working saga labels are `ArcKin Legacy`, `Echoes`, `Eternity`, and optional `New Beginnings / Paradise`.
